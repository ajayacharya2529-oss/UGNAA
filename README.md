# UGNAA NDT Service and Laboratory website

Static, responsive website. Open `index.html` in a browser or deploy the folder to any static web host.

## Business details
The website contains UGNAA's supplied contact/address/GST details and logo. Replace the `example.com` canonical, Open Graph, robots and sitemap URLs with the production domain before launch.

## Enquiry form
The enquiry form submits directly to UGNAA's business email through FormSubmit's AJAX endpoint. FormSubmit requires the recipient to confirm the initial activation email before forwarding enquiries. Submissions include the customer's contact details, selected service, preferred date, location and message. The form uses the provider's spam protection; do not disable it for a public site.

## Claims and service scope
NDT methods and application examples are illustrative. Confirm actual method availability, equipment and scope with UGNAA before treating them as offered capabilities. Project references, certifications, experience figures and testimonials are intentionally omitted.
